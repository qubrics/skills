Prepared local-file alternatives, without executing them:

An authenticated mint result is an upload intent, not a completed attachment. A later transfer uses only the exact returned method, URL and headers, with no Sendmux API key; Sending includes returned `X-Sendmux-Upload-Token`. Keep signed URLs, tokens, secret headers and API keys in memory and pass capabilities through a non-argv ephemeral channel such as stdin-fed curl configuration. Retain only the successful upload's Mailbox `blob_id` or Sending `attachment_id`; neither the intent's `upload_id` nor the other surface's ID substitutes.

Mailbox uploads cap at 7,500,000 bytes; MCP inline base64 is only for tiny agent-authored content up to 32,768 decoded bytes. Sending presigned upload authority is the specific intent's returned `max_size_bytes`, checked against exact local size before transfer; there is no universal MCP Sending presign limit. Direct upload and CLI/SDK helpers must separately obey their selected surface's current direct-upload bound; this guide supplies no numeric universal Sending direct-upload cap.
