Prepare an isolated child, without reading credentials or calling the mailbox. Clear inherited QUBRICS_API_KEY, SENDMUX_API_KEY, QUBRICS_ACCESS_TOKEN, SENDMUX_ACCESS_TOKEN, QUBRICS_PROFILE, SENDMUX_PROFILE, QUBRICS_BASE_URL and SENDMUX_BASE_URL before loading any intended credential. QUBRICS values override SENDMUX fallbacks, so the guide's SENDMUX_API_KEY="$SENDMUX_MBX_KEY" assignment alone cannot select the intended mailbox safely in the supplied parent.

For a raw-key example, obtain SENDMUX_MBX_KEY only from the user's intended secret store at eventual execution and set the child's SENDMUX_API_KEY; use a mailbox credential, never a root key. For an existing authorised profile, leave direct API-key and access-token variables unset under both prefixes and select --profile <profile> explicitly. Do not extract or print a registered agent profile's credential. Clearing both base-URL families removes the inherited endpoint; establish the approved endpoint rather than accepting the parent override.

Prepare mailbox:get-connection --profile <profile> --json without a mailbox selector before message access. Verify the intended connection and returned authorised mailbox selection; later multi-mailbox operations carry --query mailbox_id=<returned id>. Stop if credential, endpoint or mailbox identity remains uncertain. Keep secrets out of arguments, output, logs and repository files. No message read, saved draft, mutation, attachment transfer or send is executed.
